# Pocket-change-

A simple guide for organization members who need a read-only GitHub personal
access token for repository contents.

Open `index.html` to use the guide. Its button sends you to GitHub's token
creation form with the repository-reading settings prefilled. GitHub creates
and manages the token; this project does not collect or store tokens.

Review the organization and permissions on GitHub before creating a token.
Store the token securely and never share it.
