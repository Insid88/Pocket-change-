Get a repository-reading token

Create a personal access token through GitHub to get read-only access to repository contents for an organization you choose.

Continue to GitHub

What to expect

  1. GitHub opens a form with the token name, 45-day expiration, and read-only contents permission prefilled.
  2. Choose the organization that needs the token.
  3. Review the organization and permissions, then create the token in GitHub.
  4. Copy it and store it somewhere secure. GitHub may only show it once.

Your token is created and managed by GitHub. This page does not ask for, receive, or store your token. Never paste a token into this page or share it.

Tokens are personal credentials. Only create one if you need repository access.
